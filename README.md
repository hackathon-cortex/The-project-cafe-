## Cortex Contribution

- **UX Adaptation:** Tailored editorial narrative highlighting Art, Food, Design, and Hospitality.
- **Frontend Development:** Next.js 15 App Router with full static generation.
- **Responsive Implementation:** Mobile-first, desktop-refined layout with zero overflow.
- **Restaurant Menu Experience:** Semantic crawlable HTML menu with 10 verified categories and ₹ INR pricing.
- **Local-SEO Structure:** Complete Schema.org `Restaurant` + `Menu` + `OpeningHoursSpecification` JSON-LD.
- **Visual Integration:** High-fidelity imagery capturing the Yellow House ambiance, art gallery interior, wood-fired kitchen, and specialty beverages.
- **Performance Optimization:** Fully static export, zero client runtime bloat, instant transitions.

---

## Technology Stack

- **Framework:** Next.js 15 (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS v4
- **Runtime:** React 19
